# HTML Personal Portfolio Project

A complete **Personal Portfolio and Learning Journey Website** developed as part of my **HTML learning journey at Corvit Systems**.

This project demonstrates my understanding of HTML5 fundamentals, semantic elements, forms, tables, multimedia integration, accessibility, and real-world website structure using **HTML only**.

## Project Overview

This portfolio website showcases:

- Personal introduction
- Educational background
- Technical and soft skills
- Learning journey and roadmap
- Project portfolio
- Multimedia integration
- Progress tracking
- Achievements
- Frequently asked questions
- Contact information
- Sitemap navigation

The goal of this project was to apply all HTML concepts learned and build a structured, accessible, and professional website representing the **IB Afridi** brand.
